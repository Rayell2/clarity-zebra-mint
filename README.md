# ZebraMint

A Stacks blockchain platform for minting personalized NFTs with enhanced security and optimization features.

## Features
- Mint new NFTs with custom metadata (all fields required)
- Set royalty percentages for secondary sales (0-50%)
- Transfer NFTs between users with cooldown protection
- Enhanced metadata validation including image format checks
- Event logging for important state changes
- Optimized batch minting with comprehensive validation
- Read-only functions for efficient data queries

## Security Features
- Transfer cooldown mechanism
- Enhanced URL validation
- Comprehensive event logging
- Metadata format validation
